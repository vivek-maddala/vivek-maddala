# ForgePath — Project Portfolio

ForgePath is a developing product ecosystem focused on education, learning, and career development.

This repository is the public portfolio and documentation hub for three projects. It contains project descriptions and planning notes; it does **not** contain the private application source code or claim that every planned feature is live.

## Projects

| Project | Purpose | Public link |
|---|---|---|
| [EduVerse AI](eduverse-ai.md) | AI-supported student learning and academic improvement | [Open website](https://eduverseai.base44.app/) |
| [Lumovia](lumovia.md) | Courses, lessons, quizzes, and structured learning | Product information is being prepared |
| [Clarivo](clarivo.md) | Career exploration and guidance | Product information is being prepared |

## How the products relate

- **ForgePath** is the umbrella ecosystem.
- **EduVerse AI** focuses on learning and academic development.
- **Lumovia** focuses on course-based learning.
- **Clarivo** focuses on career exploration and decision support.

The products are separate experiences. Clarivo may direct learners to EduVerse AI when academic strengths and subject insights can help inform career exploration.

## Transparency

Descriptions distinguish product goals from implemented features. Availability, integrations, and feature completeness can change during development. Do not assume a feature is operational unless it is available and has been tested on the live product.
