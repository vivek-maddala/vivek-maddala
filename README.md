## 🚀 My projects

### [EduVerse AI](https://eduverseai.base44.app/)
An AI student operating system designed to help learners understand concepts, identify learning gaps, practise, and improve their academic performance.

### Lumovia
A learning platform built around courses, lessons, quizzes, doubt support, and certificates.

### Clarivo
A career-guidance platform intended to help students and professionals explore suitable paths using their interests, strengths, and learning insights.

These are evolving products. Features and availability may change as they are developed and tested.
