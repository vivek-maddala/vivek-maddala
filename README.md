# Hi, I'm Vivek Maddala 👋

**Founder of ForgePath · Student Innovator · Building digital products**

I’m a student innovator interested in using technology and AI to solve practical problems. I’m building **ForgePath**, a product ecosystem focused on education, learning, travel, and career development.

> **My approach:** Start with a real problem, build a useful product, learn from feedback, and improve it continuously.

## 🚀 The ForgePath ecosystem

| Project | What it aims to do |
|---|---|
| **ForgePath** | The parent technology venture bringing the product ecosystem together. |
| **EduVerse AI** | An AI student operating system designed to help learners understand concepts, identify learning gaps, practise, and improve. |
| **Lumovia** | A learning platform built around courses, lessons, quizzes, doubt support, and certificates. |
| **TripWay** | An AI-assisted travel planning concept for discovering destinations and organizing itineraries. |
| **Clarivo** | A career-guidance platform intended to help students and professionals explore suitable paths using their interests and strengths. |

These are evolving products. Features and availability may change as they are developed and tested.
